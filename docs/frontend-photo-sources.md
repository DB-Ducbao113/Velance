After the indicated cooldown, the official Commons imageinfo API returned downloadable published JPEG renditions (requested width 1600, or 960 for the cockpit; actual rendition dimensions listed below). Commons uses cached width buckets; decoded dimensions were checked against the filename width and source aspect ratio. Original file dimensions and SHA-1 are metadata only; the original bytes were not acquired or independently hashed. The retrieved rendition has its own SHA-256. Output width is capped at the retrieved width, preserving framing, with no upscaling. CC BY-SA images and their resized derivatives retain their listed share-alike licenses.
